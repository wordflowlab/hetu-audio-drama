# 调研依据与设计决策

## 研究方法

先检索GitHub及DSH现有公开索引，逐个clone固定research base，读取相关README、架构、专业实现和许可；SaaS仅核对公开页面声明。固定提交及文件摘要保存在research/sources.json。上游运行、收费功能和质量不因文档存在而计通过。

## 采用

采用DeepSeek Harness的贡献、服务组合与生命周期思路；河图维持外部Agent和专业工程的边界。复用河图公开SDK、同包Skill、固定来源与文件服务。参考产品的方法按本专业需求重新实现，不复制上游Agent调度、模型连接或私有数据层。

## 专业决定

首版执行PCM16 WAV混音，输入必须同采样率，支持单声道及双声道；不静默转码。输出立体声，片段有明确入出点、音量、声像和淡入淡出。峰值裁切、空白、未用录音和缺少台词覆盖如实报告。插件不内置TTS、克隆声音或模型调用；授权及费用由外部Agent与宿主固定计划处理。可解码、实际听取与作者认可分别登记。

## 许可

本包原创实现采用Apache-2.0，公开SDK快照保存来源与许可。上游研究基线不打入运行包；缺失、限制性或不同子模块许可只作为行为参考，不据公开可读推定可复制。
