# 有声剧制作产品需求

## 背景与第一性原理

作者持续积累的作品和判断，比某次生成的文字或界面存活更久。外部Agent擅长理解和生成，固定引用、版本、范围及文件处理适合确定性软件。重复要求模型重建结构会增加上下文和等待，但本产品不承诺固定token节省比例。

将角色台本、多个录音候选和效果声组织为可回放的时间线并确定性混音交付。 需要长期专业状态和可视化审阅，适合作为按需安装的插件；核心只持有通用创作事实。

## 用户与目标

小说作者、编剧、漫画作者及音频创作者通过现有Agent对话完成准备和操作，回来检查实际成果。作者可直接编辑，但不必手工重复录入已说过的信息。

## 首版完整范围

角色、台词、录音候选、时间线片段、听审意见；固定读取、增量维护、检查、比较、可恢复写入、JSON/Markdown/HTML报告、专业成果导出、包内Skill及同连接热发现。

完整流程：固定台本→角色与声音要求→外部录音或工具产出→核验真实PCM→选择片段→裁切增益声像淡入淡出→混音→听审返工→固定WAV及工程。

## 边界与非目标

首版执行PCM16 WAV混音，输入必须同采样率，支持单声道及双声道；不静默转码。输出立体声，片段有明确入出点、音量、声像和淡入淡出。峰值裁切、空白、未用录音和缺少台词覆盖如实报告。插件不内置TTS、克隆声音或模型调用；授权及费用由外部Agent与宿主固定计划处理。可解码、实际听取与作者认可分别登记。

不复制宿主正文、正式设定或版本库，不建设聊天和多Agent调度，不含发布、投放和运营。专业状态和候选不等于采纳或定稿。
