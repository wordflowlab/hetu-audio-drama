# 架构与领域设计

## 分层与技术选型

TypeScript实现领域不变量与专业用例；React展示审阅面；JSON Schema闭合输入；公开ProjectStore/SDK适配固定来源、CAS和原键。受管Node25执行插件后端，Cordis生命周期由宿主提供，插件不依赖其私有服务。Rust仅负责共享Core，不要求开发Rust扩展。

```mermaid
flowchart TB
 A[作者与外部Agent] --> E[河图稳定CLI与MCP]
 E --> P[有声剧制作 TypeScript用例]
 V[React专业工作面] --> P
 P --> D[专业领域与纯计算]
 P --> S[公开SDK ProjectStore]
 S --> C[Core作品 来源 候选 事务]
 C --> R[固定修订与可恢复记录]
```

## 本体与Owner

角色、台词、录音候选、时间线片段、听审意见属于本插件，来源中的正文、素材和正式设定属于宿主。观察、规划、模拟、实际成果与作者决定分别表达。跨插件依据保存Owner、对象、修订和摘要；不同作品必须分别操作。

## 聚合与持久化

一个专业工程是一个聚合，具有格式版本、标题、专业记录及basis_refs；宿主扩展对象携带WorkRef、Owner、Schema版本和source_refs。保存形成不可变历史修订；不引入第二个数据库。大媒体由素材库持有，工程只保存固定来源索引。

## 关键不变量

首版执行PCM16 WAV混音，输入必须同采样率，支持单声道及双声道；不静默转码。输出立体声，片段有明确入出点、音量、声像和淡入淡出。峰值裁切、空白、未用录音和缺少台词覆盖如实报告。插件不内置TTS、克隆声音或模型调用；授权及费用由外部Agent与宿主固定计划处理。可解码、实际听取与作者认可分别登记。

遵守KISS与YAGNI：仅实现当前完整旅程所需结构；共享存取由公开SDK承担，专业算法不进入Core。
